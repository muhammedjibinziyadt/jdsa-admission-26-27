# Project Memory

## Core
- Institution: "ജൗഹറത്തുൽ ഉലൂം സുഫ്ഫ ദർസ്" (Jawharathul Uloom Suffa Dars).
- Tech Stack: React, Tailwind (custom HSL), Supabase (DB/Auth/Storage), Framer Motion.
- Admin Control: All website content must be strictly CMS-editable. No dev dependency.
- Layout: Single-page flow (except Suffa page). Social links exclusively in the footer (no floating icons).
- UI Guidelines: Minimalist magazine aesthetic. Solid backgrounds, high text contrast. Compact hero banner (max 30vh mobile, 220-280px desktop).
